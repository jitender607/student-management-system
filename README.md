# Student Management System

A modern, role-based platform for managing students, attendance, marks, tasks, activity logs, and communication from one clean dashboard.

## Overview

Student Management System is a full-stack web application built for schools, teachers, and administrators who need a simple way to manage academic operations. The project combines an Express.js backend with a responsive HTML, CSS, and JavaScript frontend, using a JSON-backed data store for local development and demonstration.

The application supports role-based access for Admin, Teacher, and Student users, making it useful for academic administration, classroom tracking, and student self-service workflows.

## Features

- Secure login and signup flow with role-aware access
- Admin, Teacher, and Student dashboards
- Student record management with search and filtering
- Attendance tracking with date-based records
- Marks and performance management with academic insights
- Task management for assigning and tracking student work
- Teacher-student messaging portal
- Activity logs for important system actions
- Profile management with editable user details
- Light and dark theme support
- PDF report generation support for student records

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Backend: Node.js, Express.js
- Data storage: JSON file-based local data store
- Tooling: npm, nodemon
- Runtime: Node.js

## Installation

1. Clone the repository:

```bash
git clone https://github.com/jitender607/student-management-system.git
cd student-management-system
```

2. Install dependencies:

```bash
npm install
```

3. Start the application:

```bash
npm start
```

4. Open the app in your browser:

```text
http://localhost:3000
```
